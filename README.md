# Rectangle - Manipulation de rectangles en C++

Petit projet C++ pour illustrer la programmation orientee objet (POO) :
creation et manipulation de rectangles (aire, perimetre, carre).

## Fonctionnalites

- Creation de rectangles (largeur, hauteur)
- Calcul de l'aire
- Calcul du perimetre
- Verification si le rectangle est un carre
- Redimensionnement avec verification des dimensions

## Structure du projet

    rectangle/
    ├── include/
    │   └── Rectangle.hpp
    └── src/
        ├── Rectangle.cpp
        └── main.cpp

## Compilation

    g++ -std=c++17 -Wall -Wextra -Iinclude src/*.cpp -o Rectangle

## Execution

    ./Rectangle.exe    (Windows)
    ./Rectangle        (Linux / Mac)
